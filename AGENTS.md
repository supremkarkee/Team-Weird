# Instructions for AI coding tools

Before writing or changing any code in this repository:

1. Read `CONTRIBUTING.md` and follow every rule in it. It applies to AI-written code exactly as it applies to people.
2. Read `docs/reference-feature-vehicles.md` and build new features in the same shape.
3. Work only from the story and rule IDs you were given (e.g. US-BK-04, BR-23). Never invent fields, tables, statuses, rules, routes or screens that the spec does not contain. If something is missing, stop and say so instead of guessing.
4. Never read, print or ask for secrets, `.env` values or real personal data.
